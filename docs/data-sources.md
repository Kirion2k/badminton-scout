# Data source and rights register

The evidence for what each source may be used for. **The default is deny.** A use is allowed only when this file records evidence that the rights holder permits it. "Publicly viewable" and "technically retrievable" are facts about access, not permission.

The enforced copy of this table is `backend/src/scout/sources.py` (ADR-0002). Changing a grant there needs a PR that also updates this file with the evidence.

## Uses we assess separately

| Use | Meaning |
|---|---|
| `LOCAL_RESEARCH` | Read or analyse on a developer machine. Nothing committed, nothing shared |
| `STORE` | Copy records into our database or repository (including test fixtures) |
| `REDISTRIBUTE` | Show or hand records to anyone other than the developer, including invited testers |
| `HOSTED` | Serve from a deployed service (private or public) |
| `COMMERCIAL` | Any of the above in a paid or monetised product |

A private, invitation-only deployment is `HOSTED` + `REDISTRIBUTE`. It is not exempt.

## Request budget (until the agreements' own terms are on file)

Each authorised source: **at most 1 request per 5 s and 300 per day**, except the Tournament Software portals in `sources.py` (`www.`, `ba.` and every federation portal): **2,000 per day** from 2026-11-13 (owner instruction to grow coverage as fast as possible; same 5 s spacing). `www.` is raised to **6,000 per day** (second owner instruction, 2026-11-13) because it alone carries the history search and every owner check; same 5 s spacing, about 8.3 hours of requests a day. Each sync checks owners before searching further back. `SourceRights.min_interval_s` and `daily_budget` enforce this in `ApiAnythingProvider`. The daily count carries across ingest runs through `ingest_run.counts.requests`, and failed calls are charged for the runtime's hidden retries (ADR-0008 §4). A learning session (a handful of browser page loads, `docs/api-anything.md`) counts each page load against the same budget. **Requests used on 2026-11-12: about 50 for `ba.`** (discovery, learning, validation, imports, re-imports, two live-suite runs; each well under the 300 cap), **1 each** for `www.`, `bwf.tournamentsoftware.com` and `bwfbadminton.com`.

## Rules

- No automated requests to a path disallowed by that host's robots.txt, unless a recorded provider authorisation explicitly covers that host and path (ADR-0008).
- No bypassing 403s, challenges, logins or cookie walls.
- No third-party records in git, including test fixtures, unless `STORE` is granted. Tests use `synthetic` data.
- No live third-party requests in the default test run or CI. `live`-marked smoke tests run only on explicit request.
- Amateur and university data is personal data, so it is not ingested without a data agreement and a privacy review.
- Every ingested row keeps its source, source record key, raw payload revision and ingest run, so it can be traced and deleted on request.
